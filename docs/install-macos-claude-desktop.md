# Установка Jira-коннектора в Claude Desktop на macOS

Инструкция для пользователя без опыта разработки. После неё Claude сможет
читать задачи Jira, искать по ним, логировать время и открывать страницы
Confluence — прямо в разговоре.

**Сколько времени:** 15–20 минут, из них половина — ожидание загрузок.
**Что понадобится:** Mac, доступ к `jira.65apps.com`, около 5 минут работы в
приложении «Терминал» (всё, что нужно, — скопировать и вставить готовые строки).

---

## Как пользоваться этой инструкцией

Дальше несколько раз встретятся блоки вида:

```
какая-то команда
```

Это команды для приложения **Терминал**. Работать с ними просто:

1. Скопируйте строку целиком.
2. Переключитесь в Терминал, вставьте (⌘V) и нажмите **Enter**.
3. Дождитесь, пока снова появится строка приглашения (курсор со знаком `%`).

Терминал открывается так: нажмите **⌘ + Пробел**, наберите `Терминал`
(или `Terminal`) и нажмите Enter. Пусть он остаётся открытым до конца установки.

Пароль в Терминале не спрашивается ни на одном шаге этой инструкции.

---

## Шаг 1. Установить Claude Desktop

1. Откройте <https://claude.ai/download> и скачайте версию для macOS.
2. Перетащите Claude в папку «Программы» (Applications).
3. Запустите Claude и войдите в свою учётную запись.

Если Claude Desktop уже стоит — просто убедитесь, что вход выполнен, и переходите дальше.

---

## Шаг 2. Установить инструменты Apple для разработчиков

Коннектор скачивается из репозитория GitHub, а для этого macOS нужен `git`.
На чистом Mac его нет — он ставится одной командой.

```
xcode-select --install
```

Появится системное окно с предложением установить инструменты — нажмите
**«Установить» (Install)** и дождитесь окончания (несколько минут, ~1 ГБ).

Если вместо окна Терминал ответил `command line tools are already installed` —
всё уже стоит, ничего делать не нужно.

---

## Шаг 3. Установить `uv`

`uv` — небольшая утилита, которая скачает и запустит коннектор. Она ставится
в вашу домашнюю папку и ничего в системе не меняет.

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Проверьте, что установка прошла:

```
~/.local/bin/uv --version
```

Ответ должен быть вида `uv 0.11.15` (цифры могут отличаться — это нормально).
Если написано `No such file or directory`, повторите команду установки и
посмотрите, не было ли в её выводе ошибки.

---

## Шаг 4. Получить токены доступа

Токен — это как пароль, но только для программ. Нужны два: для Jira и для
Confluence (это разные системы со своими токенами).

**Токен Jira:**

1. Откройте <https://jira.65apps.com> и войдите.
2. Нажмите на свой аватар в правом верхнем углу → **Profile**.
3. Вкладка **Personal Access Tokens** → **Create token**.
4. Имя — например `Claude Desktop`. Срок действия — на ваше усмотрение.
5. Нажмите **Create** и **сразу скопируйте токен**: второй раз он не покажется.
6. Вставьте его во временную заметку — он понадобится на шаге 6.

**Токен Confluence:** то же самое на <https://wiki.65apps.com> (аватар →
Profile → Personal Access Tokens → Create token).

Если Confluence вам не нужен — этот токен можно пропустить, на шаге 6 будет
сказано, что убрать из настроек.

> ⚠️ Токен даёт доступ к вашим задачам от вашего имени. Не пересылайте его в
> чатах и не публикуйте. Если он утёк — удалите его на той же странице
> Personal Access Tokens и создайте новый.

---

## Шаг 5. Скачать коннектор и убедиться, что он запускается

Эта команда скачает коннектор и запустит его один раз. Первый запуск занимает
1–3 минуты — идёт загрузка.

```
~/.local/bin/uvx --from git+https://github.com/nsleader/jira-mcp.git jira-mcp
```

Вы увидите строки о загрузке пакетов, а затем **курсор просто замрёт и ничего
не будет происходить**. Это и есть признак успеха: коннектор запустился и ждёт
команд от Claude.

Нажмите **Ctrl + C**, чтобы остановить его и вернуться к приглашению Терминала.

> **Не нажимайте Enter, пока коннектор работает.** Он ждёт команд от Claude, а
> не от вас, и на пустую строку отвечает красным сообщением вида
> `ERROR Received exception from stream … Invalid JSON`. Это не поломка: просто
> нажмите Ctrl + C.

Жёлтое предупреждение `IncompleteFieldDefinitionWarning: Field 'lifespan' …`
появляется при каждом запуске у всех — оно приходит из служебной библиотеки и
ни на что не влияет.

Если вместо этого появилась ошибка со словом `git` — вернитесь к шагу 2.

Теперь узнайте точный путь к `uvx` — он понадобится в следующем шаге:

```
echo ~/.local/bin/uvx
```

Терминал напечатает что-то вроде `/Users/ivanov/.local/bin/uvx`.
Скопируйте эту строку.

---

## Шаг 6. Прописать коннектор в Claude Desktop

1. Откройте Claude Desktop.
2. Меню **Claude → Settings…** (или **⌘ + ,**).
3. Раздел **Developer** → кнопка **Edit Config**.
4. Откроется папка в Finder с файлом `claude_desktop_config.json`.
5. Нажмите на файл правой кнопкой → **Открыть в программе** → **TextEdit**.

Замените всё содержимое файла на текст ниже:

```json
{
  "mcpServers": {
    "jira": {
      "command": "/Users/ВАШ-ПОЛЬЗОВАТЕЛЬ/.local/bin/uvx",
      "args": [
        "--from",
        "git+https://github.com/nsleader/jira-mcp.git",
        "jira-mcp"
      ],
      "env": {
        "JIRA_URL": "https://jira.65apps.com",
        "JIRA_PERSONAL_TOKEN": "сюда-токен-jira",
        "CONFLUENCE_URL": "https://wiki.65apps.com",
        "CONFLUENCE_PERSONAL_TOKEN": "сюда-токен-confluence"
      }
    }
  }
}
```

Подставьте три вещи:

| Что заменить | На что |
|---|---|
| `/Users/ВАШ-ПОЛЬЗОВАТЕЛЬ/.local/bin/uvx` | строку, которую напечатал Терминал в конце шага 5 |
| `сюда-токен-jira` | токен Jira из шага 4 |
| `сюда-токен-confluence` | токен Confluence из шага 4 |

Токены вставляются **внутрь кавычек**, сами кавычки остаются на месте.

Если Confluence не нужен — удалите две строки `CONFLUENCE_URL` и
`CONFLUENCE_PERSONAL_TOKEN`, а на строке выше (`JIRA_PERSONAL_TOKEN`) уберите
запятую в конце.

Сохраните файл: **⌘ + S**. Закройте TextEdit.

> Если в файле уже что-то было (значит, у вас настроены другие коннекторы) —
> не стирайте его. Добавьте только блок `"jira": { … }` внутрь существующего
> `"mcpServers"`, поставив запятую между блоками.

---

## Шаг 7. Перезапустить Claude Desktop

Закрыть окно недостаточно — нужно завершить программу полностью:

- **⌘ + Q** (или меню **Claude → Quit Claude**), затем запустить Claude заново.

---

## Шаг 8. Проверить, что всё работает

В окне нового чата нажмите значок инструментов (**Search and tools**) под полем
ввода. В списке должен появиться пункт **jira** — а внутри 26 инструментов.

Теперь просто спросите Claude обычным языком, например:

- «Покажи задачу PROJ-123»
- «Найди мои открытые задачи в Jira»
- «Сколько часов я списал за прошлую неделю?»
- «Найди в Confluence страницы про онбординг»

Claude спросит разрешение на первый вызов инструмента — подтвердите.

---

## Если что-то не получилось

| Что видно | Что делать |
|---|---|
| Раздела **jira** нет в списке инструментов | Скорее всего, в файле настроек ошибка: лишняя или пропущенная запятая, кавычка. Откройте файл заново и сверьте с образцом из шага 6 |
| В логах `spawn ... ENOENT` | Неверный путь к `uvx` в строке `command`. Повторите последнюю команду шага 5 и вставьте её вывод |
| Claude отвечает про ошибку 401 или 403 | Токен неверный или истёк — создайте новый (шаг 4) и замените его в файле настроек |
| Инструменты Confluence жалуются на ненастроенное подключение | В настройках нет `CONFLUENCE_URL` — добавьте его (шаг 6) |
| В Терминале красное `ERROR … Invalid JSON` | Это ответ на случайно нажатый Enter, а не сбой. Нажмите Ctrl + C |
| Инструменты появились, но ответа нет / долгое ожидание | Проверьте, что вы в корпоративной сети или VPN — `jira.65apps.com` доступен не отовсюду |

Подробный технический лог лежит здесь (его можно переслать тому, кто помогает
с установкой):

```
open ~/Library/Logs/Claude/mcp-server-jira.log
```

---

## Обновление коннектора

Когда выйдет новая версия, выполните в Терминале:

```
~/.local/bin/uvx --refresh --from git+https://github.com/nsleader/jira-mcp.git jira-mcp
```

Дождитесь загрузки, нажмите **Ctrl + C** и перезапустите Claude Desktop (⌘ + Q).

## Удаление

1. Откройте файл настроек (шаг 6) и удалите блок `"jira": { … }`.
2. Перезапустите Claude Desktop.
3. Удалите токены на страницах Personal Access Tokens в Jira и Confluence.
